## Featured Project — OrbitShield

<table>
  <tr>
    <td width="60%">
      <h3>OrbitShield · Orbital Risk Engine</h3>
      <p>
        Real time satellite conjunction detection tracking <strong>16,000+ live satellites</strong> using SGP4 orbital propagation.
        A two stage spatial filter (altitude banding and orbital plane grouping) cuts collision pair comparisons from <strong>roughly 128 million to a few hundred</strong> per cycle.
      </p>
      <ul>
        <li>6 endpoint FastAPI REST service with automated background data scheduler</li>
        <li>3D interactive globe (React and Three.js) showing live orbital paths</li>
        <li>Built with Python, FastAPI, SQLAlchemy, Skyfield/SGP4, React, and Three.js</li>
      </ul>
